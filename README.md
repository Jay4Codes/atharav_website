# Atharav Samant — Portfolio

Next.js frontend for Atharav Samant's personal site. Content is drawn from his resume: dual MBA / M.S. Analytics & AI at UT Dallas, CS from UC Davis, and product work at Abhitech Energycon (AbhiStat, AbhiPMT, SmartCoke).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Content in `src/data/content.ts`

## Structure

- `src/app` — layout, homepage, metadata
- `src/components` — header, hero, work, experience, education, contact
- `src/data/content.ts` — resume-backed copy
- `public/Atharav Samant Resume.pdf` — downloadable resume
